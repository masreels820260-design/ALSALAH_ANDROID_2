# الصلاة — AL-SALAH | MAS

هذا مستودع Android Native قائم على Kotlin وJetpack Compose، ومعه ملف مواصفات تنفيذ شامل مخصص لإرساله إلى Claude:

- `CLAUDE_MASTER_PROMPT.md`: تعليمات تطوير النسخة الكاملة، إعادة التصميم Apple-inspired Liquid Glass، الوظائف، الأداء، الاختبارات، وتسليم APK.
- `.github/workflows/build-apk.yml`: GitHub Actions لبناء APK عند الدفع إلى `main` أو يدوياً.

## مهم: حالة المشروع
الملفات البرمجية الموجودة تمثل **نسخة تأسيسية** وليست إصداراً نهائياً مكتملاً. بعض الصفحات والميزات أولية، ولا ينبغي نشر التطبيق قبل استكمال المواصفات واختبار مواقيت الصلاة والتنبيهات على أجهزة فعلية. استخدم ملف `CLAUDE_MASTER_PROMPT.md` مع المشروع كاملاً واطلب من Claude تعديل الملفات فعلياً، ثم مراجعة تقرير البناء والاختبارات.

## رفعه إلى GitHub
1. فك ضغط ZIP.
2. ارفع محتويات مجلد `ALSALAH_ANDROID` إلى جذر المستودع، مع إظهار الملفات المخفية مثل `.github`.
3. افتح تبويب Actions وانتظر `Build Android APK`.
4. عند نجاح البناء افتح العملية ثم نزّل Artifact الخاص بالتطبيق.

## بناء محلي
يتطلب JDK 17 وAndroid SDK متوافقاً مع إعدادات Gradle:

```bash
gradle :app:assembleDebug
```

## تنبيهات تقنية
- دقة مواقيت الصلاة يجب مطابقتها مع مرجع مصري موثوق عبر مدن وتواريخ متعددة.
- Android والشركات المصنعة قد تؤخر التنبيهات أو تمنع الصوت بسبب صلاحيات التنبيه الدقيق، الإشعارات، وضع عدم الإزعاج، أو تحسين البطارية.
- لا يمكن للتطبيق ضمان تجاوز مستوى صوت النظام أو وضع الصامت.
- بيانات القرى والمراكز تحتاج مصدر إحداثيات موثوق؛ لا تستخدم بيانات جغرافية مخمّنة.
